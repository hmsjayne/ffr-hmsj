# Placement parity harness

Runs the browser build of Clingo (`clingo-wasm`) against placement vectors
generated by native Python Clingo. The fixture lives at
`tests/fixtures/placement_parity.json`.

Both solvers must use:

- `--configuration=frumpy`
- `--sign-def=rnd`
- one model
- the same seed

Regenerate the native vectors only when the solver configuration or ASP rules
change intentionally:

```bash
cd ../..
.venv/bin/python tools/generate_placement_vectors.py
```

Run the parity check:

```bash
npm ci
npm test
```
